# Editorial Pattern Reference

Use this as a compact review aid, not as a banned-word list.

| Pattern cluster | Editorial repair |
|---|---|
| Repeated “first / additionally / finally” signposting | Let the paragraph order carry the structure; keep signposting when the reader genuinely needs it. |
| Generic praise such as “seamless,” “robust,” or “game-changing” without proof | Replace with the concrete supported capability, or remove the praise. |
| Inflated certainty or universal promises | Narrow the claim and add a condition, source, or uncertainty marker. |
| Long opening throat-clearing | Start with the useful point for the intended reader. |
| Symmetrical contrasts repeated across paragraphs | Keep a contrast only when it clarifies a real decision; vary the structure. |
| Abstract nouns and stacked nominalizations | Prefer a concrete subject and an active verb when that keeps the meaning intact. |
| Uniform sentence lengths and paragraph cadence | Mix short and long sentences according to emphasis, without manufacturing quirks. |
| Padded conclusion that repeats the introduction | End with the next useful action, implication, or honest limitation. |

## Claim check

Before publication, ask:

- What is the main claim?
- Which supplied evidence supports it?
- Why does that evidence support the claim?
- What would a reasonable reader question or limit?
- What is still uncertain?

If an answer is missing, edit the claim to fit the evidence. Do not invent a citation or a customer outcome to complete the pattern.
