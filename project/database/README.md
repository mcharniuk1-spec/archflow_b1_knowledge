# Public contracts and generated catalogs

This folder contains the V3 data shapes used by the provider-disabled public tool. It is not a hosted database, a history archive, or a connection to an operator device. The clean release contains no customer data, private source text, personal or project memory, credentials, run traces, or prior reports.

## Current files

- `skill-catalog.json` and `skill-catalog.schema.json` describe the ten portable public skill packages.
- `role-catalog.json` and `role-catalog.schema.json` describe the 21 functional role contracts, including packaged skills and method checklists.
- `run-envelope.schema.json` defines one bounded controller case.
- `runtime-event.schema.json` defines a sanitized event shape; its presence does not claim a live event stream.
- `review-bundle.schema.json` defines a reviewable browser export.
- `action-receipt.schema.json` defines exact action and readback evidence.
- `solution-memory-record.schema.json` defines reviewed reusable meaning with lineage, freshness, and supersession.

`skill-catalog.json` and `role-catalog.json` are generated by `project/scripts/generate-dashboard-data.py`; do not edit them by hand. The generator also builds `project/dashboard/data.json` and its identical `data.js` fallback from the exact corpus manifest, catalogs, four role packs, provider registry, workflow, boundaries, and fixed benchmark result. It does not add run summaries or expand unlisted directories.

## Runtime boundary

The dashboard reads the generated projection and keeps a case draft plus short event summaries in browser storage. It has no SQL console and cannot query a private or production database. Browser state is not a canonical run, shared collaboration record, or durable memory store.

A future single-user evidence ledger would need migrations, a read-only query role, time and row limits, audit, backup and restore proof, and strict corpus separation. A hosted multi-user database additionally needs verified tenancy, authentication, RBAC, encryption, retention, and operational recovery. None is claimed by the public V3 release.
