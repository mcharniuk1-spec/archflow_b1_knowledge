Workflow / 02 Research → define → act → review → remember

One operating model for an individual or a team.

Start with the provider-disabled public core. Frame one decision and exact evidence boundary, activate the smallest role and skill set, keep state visible, and separate an approved external action from the planning that precedes it.

01Individual workspace

One operator, explicit contracts

Coordinate several responsibilities without hiding the review boundary.

  • ResearchAdmit sources, retrieve narrowly, verify exact passages, and name gaps.
  • DefineBind the decision, output, acceptance checks, authority, reviewer, and stop.
  • ActPrepare one bounded candidate; keep provider and write permissions separate.
  • ReviewFreeze the candidate, run deterministic checks, and record a verdict.

What these measurements compare

Context input compares the top-five deterministic lexical packet with four full-manifest packets in UTF-8 bytes. Role activation compares the smallest declared role packs with all-21-role fan-out over four tasks. Source recall checks whether the expected canonical file appears in the top five. Semantic gates use one valid and seven unsafe or incomplete packets. Rerun after every corpus, role, or fixture change.
