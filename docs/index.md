## Status vocabulary

- `documented` — maintained explanation and source exist;
- `configured` — a parseable contract exists, but execution is not proved;
- `locally tested` — the named deterministic fixture passed;
- `independently reviewed` — a frozen candidate received a separate verdict;
- `approved action` — one exact target and effect received the required authority;
- `read back` — target state was observed after the action;
- `promoted knowledge` — reviewed reusable meaning was admitted with lineage and freshness.

If current files conflict, stop and record the gap instead of silently combining incompatible claims.
